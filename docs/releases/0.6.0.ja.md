# 0.6.0 リリース

対象: [turbowarp-plus-editor#774](https://github.com/kubohiroya/turbowarp-plus-editor/issues/774) の受け入れ基準1（kamishibai 3.2 規模の作品にテストを書いて動かす）。ブランチ: `chore/release/0.6.0`、base: `d184b1b`。

PR #13 の、Editor がサンドボックスの外で動かした拡張をテストでも同じく動かす変更を配布版へ反映します。

- Plus の拡張の記録から読む拡張は、Editor が承認したのと同じ ID・SHA-256 のときだけサンドボックスの外で動かす。
- 作品が URL で参照する拡張は、Editor が実際にサンドボックスの外で読んだ URL のうち、作品が名指すものだけを外で読む。data URL は URL が中身そのもの。https の URL は Editor と同じく URL で信頼する。
- 保存した世代のテストには、この承認を持ち込まない。

Editor から frame へ送る `context` に項目を足すため、minor を上げます。この候補は package.json と lockfile の版を 0.5.0 から 0.6.0 へ進め、この記録を足すだけです。

## 公開手順

0.5.0 と同じ。`npm test` とヘッドレスの `npm run test:browser` → PR の CI 後に Squash Merge → マージコミットからビルド・pack → `v0.6.0` タグと GitHub Release → 同じアーカイブを npm（latest）に公開 → registry の shasum を照合 → Editor の依存を固定。

## 切り戻し

公開前はこの版変更を revert します。公開後は同じ npm 版を置き換えず、Editor の依存を 0.5.0 に戻します。0.5.0 の frame は、サンドボックスの外を要求する拡張を使う作品のテストを始めずに止めます。
